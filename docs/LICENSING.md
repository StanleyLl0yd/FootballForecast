# Data and software licensing

Data-provider terms and competition rights are distinct. An API subscription does not automatically include rights to redistribute match records, club emblems or statistics. Private local analysis may have a different permission scope from a published commercial product. The source permission register is in `DATA_SOURCES.md`; all sources remain unapproved at M0.

Do not retrieve FootyStats site content by automation; its terms exclude its distinct API from the website scraping ban. Confirm API license and retention rights separately. Never copy real team logos into frontend without permission. No vendor raw data committed to Git. Software project LICENSE has not yet been selected by the owner; until selected, do not assume permission to redistribute this code outside private use.
