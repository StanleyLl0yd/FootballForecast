# Known limitations - M0

- The public, anonymous read-only prototype is deployed to Vercel Hobby, functions in Frankfurt; GitHub-hosted HTTP smoke verified the live site and the server-side Supabase REST read. **Access from Russian ISPs without VPN is not measured**. No commercial hosting is approved.
- Supabase Free PostgreSQL 17 in Frankfurt has three applied migrations and nine RLS tables. Six are anonymous SELECT-only; source rights, raw records and access grants remain private. The real database is empty, so there are no licensed RPL matches, model results or forecasts.
- On 2026-10-20, the same [read-only nine-table anonymous privilege/RLS catalog attestation](../database/tests/0005_live_anon_posture.sql) was executed against **live** PostgreSQL 17.11: PASS, 9 exact tables, 0 grant/policy mismatches, 0 anonymous write policies and 0 anonymous-callable SECURITY DEFINER functions. This proves live SQL catalog posture and is also required on disposable PG17 CI; **it does not** prove live PostgREST HTTP 401/403 behavior, real external encrypted backup, or recovery.
- Automated CI now starts **real PostgREST v14.14** on the same disposable PostgreSQL 17 fixture and sends eight HTTP operations under the `anon` role: one permitted SELECT, three denied private reads, and four denied writes. The test uses an isolated unprivileged login and automatic transaction rollbacks, with no live Supabase key or production HTTP connection. This supplies actual REST-framework evidence **on CI only**, not a live Supabase PostgREST test, real backup or restoration.
- Reproducible npm lockfile and `npm ci`, GitHub CI/Security/CodeQL, disposable PostgreSQL RLS tests, Node HTTP tests, and headless Chrome smoke pass. Headless Safari, Firefox and Edge have passed automated diagnostics, but real Russian-network/browser combinations, an offsite actual Supabase Free PostgreSQL 17 backup/restore and optional owner OAuth lifecycle tests are not demonstrated. The synthetic dump is restored to a **separate** PostgreSQL 17 container within one CI runner.
- Accounts are intentionally deferred. The optional owner-only OAuth route remains fail-closed and administrative mutations are disabled. Do not require owner login for ordinary public pages or claim operational admin access.
- Python Poisson primitives accept input intensities but have not learned strengths, been calibrated or passed real historical backtests. Data sources lack final rights approval: **no scraping, import, paid feed or fabricated fixtures**.
- A **one-time research-only** bounded Footbolno RPL CSV observation on 2026-10-20 found a *source-reported* 2026/27 schedule of 240 matches (88 marked finished, 152 scheduled). Five earlier seasons (2016/17-2020/21) have source structural anomalies and are explicitly quarantined. Current-season availability is NOT independent match correctness, a right to import/train, or historical as-of timestamp evidence. Raw provider rows remain outside Git/Supabase; see `docs/M0_FOOTBOLNO_RPL_AGGREGATE_EVIDENCE.json`.
- Evaluation and model contracts are partial; filters, detailed match predictions, independently validated charts and user profiles are not yet implemented. Publication/temporal-integrity guards are in SQL, but a functioning authorized prediction worker and backup/restore acceptance remain future work.
- An unresolved high-severity advisory in transitive ESLint development dependency `braces` (GHSA-vfj7-8cjw-p6xm) is tracked in issue #8; enforced production-only audit is clean. The full npm audit now **fails CI for every new HIGH/CRITICAL finding**, except for an exact, explicitly validated dev-only ESLint chain carrying this still-unpatched single advisory. No patched version has been confirmed; issue #8 remains OPEN. CSP hardening and external security review remain open.
- Vercel deployment status and canary success do not establish availability under Russian operator filtering, future scalability or legality of storage/processing for possible future Russian user accounts.

M0 remains OPEN. M1 may not start until the owner accepts M0.

- Optional OAuth token refresh is scoped to administrator requests; ordinary visitors do not need an auth session. Real owner OAuth E2E remains deferred.

- Public archive now queries the last 20 immutable predictions with timestamp, model, hash and 1X2 probabilities; evaluation charts, match details, source rights and actual historical forecasts remain missing. The real archive has zero records until a licensed pipeline exists.

- Cross-browser CI success does not prove availability from Russian residential or mobile carriers without a VPN. Real end-user reachability requires independent operator observations.
