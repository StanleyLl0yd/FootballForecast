# FootballForecast

**Публичная футбольная аналитика на проверяемых данных, а не на уверенных догадках.**

[Открыть приложение](https://footballforecast.vercel.app) · [План разработки](ROADMAP.md) · [Ограничения](docs/KNOWN_LIMITATIONS.md)

**Статус: M1 ACCEPTED (02.11.2026); M2 OPEN (02.11.2026), переход на OpenFootball-first (03.11.2026).**

Исторические workflow M0, обращавшиеся к Footbolno после push, переведены в ручной режим только для владельца; регрессионный тест проверяет отсутствие автоматического сетевого запроса к этому источнику. Рабочее обучение M2 не зависит от Footbolno. M0 принят 29.10.2026. Приложение работает на бесплатных Vercel Hobby (`fra1`) и Supabase Free Frankfurt. Публичная статистика РПЛ доступна без регистрации. На момент подтверждённого защищённого импорта 01.11.2026 в приватной базе находятся **4 полных снимка по 720 матчей (2880 записей)** и **2 компактных SHA-наблюдения**. Опубликовано **616 матчей (583 завершённых, 33 запланированных)**; 104 будущих матча без точного времени остаются приватными. Зафиксировано **7 неизменяемых событий переходов**, включая четыре результата 01.11.2026; holdout 2025/26 не изменился. Прежний Footbolno импорт сохранён только для ручного аварийного вызова: расписание и push-запуск отключены, поскольку работа от источника больше не зависит. **Утверждённых и опубликованных моделей, прогнозов и подтверждённой точности пока нет.** Два независимых временных обучения в защищённых исследовательских заданиях завершились с одинаковым SHA модели; коэффициенты не сохранялись.

**Подтверждено двумя реальными train-only запусками 03.11.2026:** [#41601074078](https://github.com/StanleyLl0yd/FootballForecast/actions/runs/41601074078) и [#41601164752](https://github.com/StanleyLl0yd/FootballForecast/actions/runs/41601164752) дали одинаковые SHA модели/выборки/источника. [Закреплённые агрегированные доказательства](docs/M2_OPENFOOTBALL_TRAIN_REPLAY_EVIDENCE.json) не содержат исходных строк, имён клубов или коэффициентов. Модель не сохранена и не утверждена; holdout не читался. Это не доказательство точности или воспроизводимости текущих прогнозов.

**Подготовка immutable lock:** закрытый канонический кодек коэффициентов теперь различает старый протокол и OpenFootball-first по fingerprint, с синтетическими тестами на подмену. Реальная модель по-прежнему не сохранялась; независимая проверка источника 2025/26, защищённое хранение и фиксация ещё не выполнены. [Ограничения](docs/M2_OPENFOOTBALL_PROTOCOL.md#calendar-only-private-coefficient-encoding--preparation-not-a-study-lock-2026-11-03).

**Реальная проверка источников 03.11.2026:** защищённый [GitHub Actions #41613346756](https://github.com/StanleyLl0yd/FootballForecast/actions/runs/41613346756) подтвердил OpenFootball 2024/25 (240 матчей), но OpenFoot 2026/27 вернул лишь 5 записей, а SportScore не подтвердил матчей в выбранный UTC-день. [Закреплены только проверяемые агрегаты и SHA](docs/M2_PUBLIC_SOURCE_OBSERVATION_EVIDENCE.json), не исходные результаты. **Текущий полноценный источник РПЛ не одобрен; 2025/26 holdout закрыт, M2 4/8.**

**Резервная проверка OpenFoot через клубы:** после неоднозначного результата проверки первого тура подготовлена ручная защищённая команда `/m2-openfoot-teams` в issue #182 (или `openfoot_teams=AUDIT_OPENFOOT_TEAMS` в workflow). Она использует 16 документированных фильтров команд бесплатного Starter без платной пагинации; возвращает только числовые агрегаты, не вводит импорт/прогнозы и не открывает контрольный сезон. [Контракт](docs/M2_OPENFOOTBALL_PROTOCOL.md#openfoot-free-team-filter-fallback-2026-11-03).

**Проверка полноты OpenFoot без платной пагинации:** после подтверждённого 50-матчевого результата бесплатного Starter добавлена отдельная ручная команда `openfoot_rounds=AUDIT_OPENFOOT_ROUNDS` (или `/m2-openfoot-rounds` в issue #182 только от владельца) для просмотра до 30 туров РПЛ 2026/27 с тем же закрытым секретом GitHub Actions. Она возвращает только агрегаты, не скачивает платные страницы и не включает прогнозы. [Контракт и ограничения](docs/M2_OPENFOOTBALL_PROTOCOL.md#real-0-starter-observation-and-exact-round-audit-2026-11-03).

**Дополнительная проверка OpenFoot Starter без платных тарифов:** ручной защищённый workflow поддерживает необязательную команду `openfoot_starter=AUDIT_OPENFOOT_FREE` с приватным GitHub Actions secret `OPENFOOT_API_KEY`. Выполняется один запрос сезона 2026/27 с проверкой полноты и прав доступа; только агрегаты и SHA, без импорта или прогнозов. Без ключа результат `INCONCLUSIVE` (запрос не отправляется). [Правила проверки](docs/DATA_SOURCES.md#explicit-owner-only-openfoot-free-starter-coverage-audit-2026-11-03).

**Диагностика источника текущей РПЛ:** в ручной защищённый workflow публичных наблюдений добавлена одна ограниченная проверка бесплатного документационного demo OpenFoot API для сезона 2026/27. Только агрегаты/SHA, без ключа пользователя, без автоматического импорта или разрешения публикации. Полная и лицензированная актуальность источника остаётся неподтверждённой.

**Новый источник исследования:** [протокол OpenFootball CC0 calendar-only](docs/M2_OPENFOOTBALL_PROTOCOL.md) и [ручной защищённый train-only workflow](https://github.com/StanleyLl0yd/FootballForecast/actions/workflows/m2-openfootball-train-only.yml). Он получает точно закреплённые 240 матчей РПЛ 2024/25 непосредственно из OpenFootball, не обращаясь к Footbolno или Supabase. Git blob проверяется до обучения, исходные календарные даты сохраняются без поддельного времени, а результаты fit остаются временными и без точности/прогнозов. Контрольный сезон 2025/26 и текущие матчи требуют отдельной доказанной бесплатной схемы; существующий holdout закрыт.

Для независимых проверок доступен ручной [M2 public-source research](https://github.com/StanleyLl0yd/FootballForecast/actions/workflows/m2-public-sources-observe.yml): подтверждение точного OpenFootball-файла и односуточная проверка SportScore без Footbolno, секретов, публикации строк матчей и записи в БД. Защищённый запуск разрешён только владельцу, также через точную команду `/m2-public-sources` в [issue #182](https://github.com/StanleyLl0yd/FootballForecast/issues/182). Недоступность API обозначается как `INCONCLUSIVE`, а не отсутствие матчей.

При недоступности Footbolno добавлен самостоятельный [строго закреплённый read-only адаптер OpenFootball](docs/DATA_SOURCES.md#m2-source-outage-independent-reference-path-2026-11-03) для структурной проверки РПЛ 2024/25: 240 матчей, 16 клубов, SHA исходного Git blob, отдельные агрегаты. Он не заменяет неизменяемые исходные Footbolno-данные M2, не выдумывает точное время матчей и не открывает контрольный сезон. SportScore остаётся ограниченным дополнительным источником текущих результатов, без автоматического переключения моделей.

В M2 подготовлен [защищённый read-only адаптер выборки 2024/25](docs/M2_TRAINING_INPUT.md) с проверками сезона, provenance и хронологии. Миграция установлена в Supabase Frankfurt; агрегатная проверка подтвердила 240/240 тренировочных матчей и 16 клубов, без вывода приватных записей. [Защищённый preflight](https://github.com/StanleyLl0yd/FootballForecast/actions/runs/41442233583) подтвердил 240 матчей и 16 клубов. [Два реальных временных обучения](https://github.com/StanleyLl0yd/FootballForecast/issues/182#issuecomment-6576955508) Independent Poisson v1 на сохранённом train-only снимке успешно завершились с одинаковыми SHA данных, карты клубов и модели. Footbolno при этих запусках не запрашивался; holdout 2025/26 не раскрыт. Это исследовательские кандидаты, а не утверждённые модели.


Для M2 добавлен синтетически тестируемый [механизм фиксации исследования до вскрытия holdout](docs/M2_RESEARCH_LOCK.md): SHA обучающих строк, сопоставления клубов, fitted-модели, исходного CSV и Git-коммита. Защищённый ручной train-only запуск для SHA-фиксации подготовлен с двумя ручными входами — GitHub Actions и строго проверяемая команда владельца в issue #182 (без автоматического запуска при push); результат пока не подтверждён. Чистый агрегированный оценщик Log Loss/Brier/RPS проверен только на синтетике; реальный фиксирующий запуск и контрольная оценка пока **не выполнялись**; независимость первичных поставщиков и историческая доступность данных не доказаны.

В разделе [«Лаборатория моделей»](https://footballforecast.vercel.app/models) подготовлен публичный read-only статус и локальная проверка JSON-аттестата (только агрегаты/SHA, до 16 КиБ). Также доступно [закреплённое агрегированное evidence двух временных запусков](docs/M2_STORED_TRAIN_REPLAY_EVIDENCE.json) с исходными GitHub Actions ссылками и проверяемым SHA отчёта; источник Footbolno в них не перепроверен, модель не утверждена. Файл никуда не загружается; локальный просмотр не доказывает подлинность GitHub-запуска или завершённость исследования. Сервер дополнительно запрашивает только общедоступный статус защищённого GitHub Actions через ограниченный GET без токена; недоступность API не приравнивается к отсутствию запусков.

Добавлен [защищённый рабочий экран владельца](https://footballforecast.vercel.app/admin/research) для read-only контроля M2: закреплённые SHA двух train-only запусков, метаданные последних ручных train-only и OpenFootball/SportScore GitHub Actions, явные блокирующие условия независимой сверки источника, неизменяемой фиксации модели и запрет на чтение holdout. Доступ защищён `requireOwner()`; при не настроенном GitHub OAuth выполняется перенаправление на страницу настройки, а не обход проверки. Экран ничего не обучает, не импортирует и не записывает в Supabase. В нём также можно локально проверить JSON будущего запроса на неизменяемую фиксацию исследования: только закрытая схема, SHA и статус ожидания независимой проверки; ни подлинность задания, ни разрешение на holdout этим не подтверждаются. Локальная проверка отчётов остаётся доступной в публичной лаборатории и на защищённом экране. Это шаг по UI, а не приёмка полного критерия #182.


Добавлен синтетически проверяемый приватный кодек будущего хранения модели: детерминированные байты коэффициентов с закрытой схемой и сверкой SHA-256. **Реальные коэффициенты не сохранялись, шифрование и защищённое хранилище не включены**, никакого допуска к holdout это не даёт. Подробности — в [контракте исследования](docs/M2_RESEARCH_LOCK.md#canonical-private-model-codec-synthetic-only-no-escrow-executed).

Подготовлен синтетически проверяемый [черновик метаданных будущей неизменяемой фиксации](docs/M2_RESEARCH_LOCK.md#synthetic-only-anchor-request-envelope-not-an-accepted-lock): обязательные SHA модели, источника, задания и среды. Это **не** утверждённый lock, не сохранение коэффициентов и не допуск к holdout.

Условная задача по Elo/Dixon–Coles закрыта [документированным переносом выбора альтернативных моделей](docs/M2_BASELINE_PROTOCOL.md#conditional-model-family-decision--2026-11-02): независимой валидационной выборки нет, holdout использовать для подбора запрещено. **M2 4/8; четыре задачи остаются открытыми.**

M2 пока находится на этапе разработки: **утверждённых или сохранённых обученных моделей, опубликованных прогнозов и подтверждённой точности нет**. Контрольный сезон 2025/26 запрещено использовать для подбора параметров. M3 ещё не открыт.

## Принципы

- **РПЛ, прежде всего «Зенит».** В перспективе - другие лиги и международная аудитория.
- **Воспроизводимость.** Временная корректность данных, исходные версии, хэши и неизменяемый архив прогнозов.
- **Измеряемое качество.** Вероятности П1/Х/П2 и проверка Log Loss, Brier, RPS и калибровки на независимых исторических данных.
- **Права на данные.** Никакого неразрешённого скрапинга, вымышленных матчей или публикации поставщицких данных без лицензии.
