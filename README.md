# FootballForecast

**Публичная футбольная аналитика на проверяемых данных, а не на уверенных догадках.**

[Открыть приложение](https://footballforecast.vercel.app) · [План разработки](ROADMAP.md) · [Ограничения](docs/KNOWN_LIMITATIONS.md)

**Статус: M1 OPEN, основа данных подключена.** M0 принят 29.10.2026. Приложение Next.js развёрнуто на бесплатном Vercel Hobby во Франкфурте, Supabase Free также работает во Франкфурте. Обзор и результаты РПЛ доступны **без регистрации**, администраторские операции закрыты. На 29.10.2026 импортировано 720 реальных записей Footbolno (CC BY 4.0) в приватное хранилище; 616 матчей опубликованы с подтверждённым временем, 104 будущих матча без точного часа сохранены приватно. Все 19 клубов и три сезона сопоставлены с каноническим каталогом. Защищённое сравнение версий и ограниченное обновление текущего сезона реализованы, но второй реальный снимок с новым SHA-256 проверен 30.10.2026 (720 матчей без изменений), однако реальное изменение матчей по обновлённому снимку ещё не наблюдалось. Защищённый импорт запускается автоматически в 06:17 и 18:17 UTC, а бесплатная проверка SportScore на текущий день - в 07:43 UTC. **Обученных моделей, опубликованных прогнозов и подтверждённой точности пока нет.**

## Принципы

- **РПЛ, прежде всего «Зенит».** В перспективе - другие лиги и международная аудитория.
- **Воспроизводимость.** Временная корректность данных, исходные версии, хэши и неизменяемый архив прогнозов.
- **Измеряемое качество.** Вероятности П1/Х/П2 и проверка Log Loss, Brier, RPS и калибровки на независимых исторических данных.
- **Права на данные.** Никакого неразрешённого скрапинга, вымышленных матчей или публикации поставщицких данных без лицензии.

```sh

npm run dev
python -m pip install -e 'ml[test]'
python -m pytest ml/tests -q
```
