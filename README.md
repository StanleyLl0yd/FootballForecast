# FootballForecast

**Публичная футбольная аналитика на проверяемых данных, а не на уверенных догадках.**

[Открыть приложение](https://footballforecast.vercel.app) · [План разработки](ROADMAP.md) · [Ограничения](docs/KNOWN_LIMITATIONS.md)

**Статус: M1 ACCEPTED (02.11.2026); M2 OPEN (02.11.2026), разработка базовой модели начата.** M0 принят 29.10.2026. Приложение работает на бесплатных Vercel Hobby (`fra1`) и Supabase Free Frankfurt. Публичная статистика РПЛ доступна без регистрации. На момент подтверждённого защищённого импорта 01.11.2026 в приватной базе находятся **4 полных снимка по 720 матчей (2880 записей)** и **2 компактных SHA-наблюдения**. Опубликовано **616 матчей (583 завершённых, 33 запланированных)**; 104 будущих матча без точного времени остаются приватными. Зафиксировано **7 неизменяемых событий переходов**, включая четыре результата 01.11.2026; holdout 2025/26 не изменился. Защищённый импорт запускается по расписанию и при изменениях доверенных файлов на `main`. **Обученных моделей, опубликованных прогнозов и подтверждённой точности пока нет.**

В M2 подготовлен [защищённый read-only адаптер выборки 2024/25](docs/M2_TRAINING_INPUT.md) с проверками сезона, provenance и хронологии. Миграция установлена в Supabase Frankfurt; агрегатная проверка подтвердила 240/240 тренировочных матчей и 16 клубов, без вывода приватных записей. Обучение ещё не проводилось; holdout 2025/26 не раскрыт.

M2 пока находится на этапе разработки: **обученных на реальных матчах моделей, опубликованных прогнозов и подтверждённой точности нет**. Контрольный сезон 2025/26 запрещено использовать для подбора параметров. M3 ещё не открыт.

## Принципы

- **РПЛ, прежде всего «Зенит».** В перспективе - другие лиги и международная аудитория.
- **Воспроизводимость.** Временная корректность данных, исходные версии, хэши и неизменяемый архив прогнозов.
- **Измеряемое качество.** Вероятности П1/Х/П2 и проверка Log Loss, Brier, RPS и калибровки на независимых исторических данных.
- **Права на данные.** Никакого неразрешённого скрапинга, вымышленных матчей или публикации поставщицких данных без лицензии.

Локальная разработка:

```sh
npm ci
npm run dev
python -m pip install -e 'ml[test]'
python -m pytest ml/tests -q
```
