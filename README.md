# FootballForecast

**Публичная футбольная аналитика на проверяемых данных, а не на уверенных догадках.**

[Открыть приложение](https://footballforecast.vercel.app) · [План разработки](ROADMAP.md) · [Ограничения](docs/KNOWN_LIMITATIONS.md)

**Статус: M0, разработка.** Next.js уже развёрнут на бесплатном Vercel Hobby во Франкфурте; Supabase Free также работает во Франкфурте. Обзор и каталог матчей доступны **без регистрации**. Админский раздел закрыт; импорт данных, обучение моделей и публикация реальных прогнозов пока не включены. База РПЛ ещё пустая. Нет подтверждённой точности прогнозирования.

## Принципы

- **РПЛ, прежде всего «Зенит».** В перспективе - другие лиги и международная аудитория.
- **Воспроизводимость.** Временная корректность данных, исходные версии, хэши и неизменяемый архив прогнозов.
- **Измеряемое качество.** Вероятности П1/Х/П2 и проверка Log Loss, Brier, RPS и калибровки на независимых исторических данных.
- **Права на данные.** Никакого неразрешённого скрапинга, вымышленных матчей или публикации поставщицких данных без лицензии.

Локальная разработка:

```sh
npm ci
npm run dev
python -m pip install -e 'ml[test]'
python -m pytest ml/tests -q
```
